# Upgrade Gift

Telegram-бот, который отслеживает улучшение подарков в Telegram и сразу присылает в чат:

- ссылку на подарок (`t.me/nft/...`) с превью;
- флор коллекции ($ по оценке Telegram и минимальная цена в ⭐ на маркете);
- владельца подарка;
- доступен ли подарок к передаче.

Плюс мини-апп на **jsqvpn.online**: покупка подписки через **xRocket** и настройка уведомлений.
Без активной подписки бот уведомления не присылает.

| Тариф | Цена |
|---|---|
| 1 день | 1 $ |
| 30 дней | 25 $ |
| 90 дней | 60 $ |

Оплата в USDT (меняется в `XROCKET_CURRENCY`), тарифы — в `upgrade_gift/config.py`.

## Как это работает

Bot API не сообщает об улучшениях подарков, поэтому мониторинг идёт через MTProto от
обычного аккаунта-сканера (Telethon). Каждый улучшенный подарок получает следующий
номер в коллекции (`PlushPepe-1`, `PlushPepe-2`, …). Монитор запоминает последний номер
каждой коллекции и опрашивает следующий: как только он появляется — подарок только что улучшили.

**Доступность передачи** определяется по публичным данным подарка:
- ✅ подарок в Telegram — можно передать;
- 🏷 выставлен на продажу (с ценой);
- ⛓ выведен в блокчейн TON — передать через Telegram нельзя;
- 🔥 сожжён.

Личные ограничения владельца (например, временная блокировка передачи после покупки)
Telegram третьим лицам не показывает.

## Настройки в мини-аппе

- вкл/выкл уведомления, режим без звука;
- что показывать: флор, владельца, статус передачи, модель/фон/узор;
- фильтры: только доступные к передаче, только с открытым владельцем, номер до N,
  флор от/до $, редкость модели до X %;
- выбор коллекций (по умолчанию — все).

## Поиск юзернеймов для ботов

Вкладка «Ники» в мини-аппе (только с подпиской):

- **ручная проверка** — слова + окончания `ai`, `game`, `app`, `agent`, `bot`;
- **фоновый поиск** — бот сам перебирает ~2600 «красивых» вариантов (слова из `upgrade_gift/words.txt`, короткие и
  «денежные» слова: pay, nft, ton, vip, x, go…) и показывает лучшие свободные и
  выставленные на Fragment;
- **оценка 0–100** — чем короче имя и ценнее слово, тем выше;
- **уведомления** — админам (`ADMIN_IDS`) бот сам присылает все свободные находки сводкой раз в минуту; подписчики включают это в мини-аппе.

Проверка: сначала страница `t.me/<имя>` (есть — занято), затем точный ответ
Telegram (`account.checkUsername`): свободно / продаётся на Fragment / занято.
Скорость — `USERNAME_CHECK_INTERVAL` (по умолчанию 4 с между проверками).

## Запуск на сервере

Нужны Ubuntu/Debian, root и A-запись `jsqvpn.online` → IP сервера. Если порты 80/443 свободны,
HTTPS делает встроенный Caddy; если их занимает nginx — скрипт подключит мини-апп к nginx и выпустит сертификат через certbot.

```bash
apt-get update && apt-get install -y git curl
git clone -b claude/upgrade-gift-telegram-bot-hiyoyv https://github.com/Jaredsss/GiftTransfer /opt/gift
cd /opt/gift
BOT_TOKEN=... XROCKET_API_KEY=... TG_API_ID=... TG_API_HASH=... bash deploy/install.sh
```

Скрипт установит Docker, заполнит `.env`, попросит войти в аккаунт-сканер
(номер, код, пароль 2FA) и запустит бота вместе с Caddy (HTTPS для мини-аппа).

- Обновление: `cd /opt/gift && git pull && bash deploy/install.sh`
- Логи: `cd /opt/gift && docker compose logs -f bot`
- Вебхук xRocket (необязательно, счета и так проверяются каждые 20 с):
  `https://jsqvpn.online/xrocket/webhook`

```
  main.py       запуск всех компонентов
  bot.py        команды бота
  monitor.py    отслеживание улучшений (MTProto)
  gifts.py      разбор данных подарка
  notifier.py   фильтры, текст и рассылка уведомлений
  payments.py   xRocket Pay: счета, вебхук, активация подписки
  webapp.py     API мини-аппа и раздача статики
  db.py         SQLite
webapp/         мини-апп (HTML/CSS/JS)
```
