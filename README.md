# Rocket — кошелёк для OceanGram

Бот-кошелёк в стиле крипто-кошельков Telegram, работает в OceanGram через его Bot API
(`https://oceanment.space`, совместим с Telegram Bot API).

## Возможности

- **Постоянные адреса** — при первом запуске каждому пользователю создаются адреса
  для трёх валют, закреплённые навсегда:

  | Валюта | Пример начала | Длина |
  |---|---|---|
  | 💵 USDT | `USDT…` | 34 (как TRON) |
  | 💎 GRAM | `GRAM…` | 48 (как TON) |
  | 🟠 BTC | `btc1q…` | 42 (как bech32) |

  В конце адреса — контрольная сумма: адрес с опечаткой бот не примет.
- **Переводы** — по адресу или @username, без комиссии; получатель получает уведомление.
- **Обмен** — между USDT, GRAM и BTC по рыночному курсу (комиссия `SWAP_FEE_PERCENT`).
- **Курсы** — USDT и BTC берутся с CoinGecko (запасной источник — Binance), всё показывается
  в звёздах OceanGram вместо рублей. Цена звезды — `STAR_PRICE_USD`, GRAM — `GRAM_PRICE_USD`
  (или `GRAM_COINGECKO_ID`).
- **Чеки** — ссылка, по которой забирают монеты, на одного или нескольких человек.
- **P2P-маркет** — покупка/продажа монет за звёзды:
  - объявления на продажу и покупку, цена, лимиты, способ оплаты, условия;
  - монеты продавца блокируются (эскроу) и уходят покупателю только после подтверждения;
  - «Я оплатил» → продавец подтверждает получение → монеты зачисляются;
  - неоплаченные сделки отменяются автоматически (`P2P_PAY_MINUTES`);
  - чат по сделке через бота;
  - **споры**: любая сторона открывает спор, модераторы получают сделку с кнопками
    «Отдать покупателю» / «Вернуть продавцу» и видят переписку.
- **История** операций.

Монеты внутренние: существуют только внутри бота. Новые монеты выпускает администратор
(`/mint`), дальше они ходят между пользователями через переводы, P2P, обмен и чеки.

## Админ-команды

```
/admin                         статистика и список команд
/mint <кому> <валюта> <сумма>  начислить монеты
/burn <кому> <валюта> <сумма>  списать
/user <кому>                   балансы и адреса
/ban, /unban <кому>
/disputes                      открытые споры
```
«Кому» — id, @username или адрес кошелька.

## Запуск на сервере

```bash
apt-get update && apt-get install -y git curl
git clone -b claude/upgrade-gift-telegram-bot-hiyoyv https://github.com/Jaredsss/GiftTransfer /opt/rocket
cd /opt/rocket
BOT_TOKEN=... ADMIN_IDS=... bash deploy/install.sh
```

- Обновление: `cd /opt/rocket && git pull && docker compose up -d --build`
- Логи: `cd /opt/rocket && docker compose logs -f rocket`
- Данные (SQLite) — в `/opt/rocket/data`.

## Структура

```
rocket/
  main.py          запуск, подключение к OceanGram
  currencies.py    валюты, суммы, адреса
  db.py            балансы, переводы, чеки, P2P (атомарные транзакции)
  rates.py         курсы
  ui.py            кнопки и форматирование
  handlers/
    wallet.py      кошелёк, переводы, обмен, чеки, история, курсы
    p2p.py         P2P-маркет и споры
    admin.py       админ-команды
```

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```
Сквозной тест гоняет бота через поддельный Bot API: переводы, обмен, чеки, P2P-сделку и спор.
